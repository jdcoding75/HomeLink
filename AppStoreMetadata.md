## Review Notes (for App Review)

```
Pointward is a compass that points toward saved people and lets paired users send small animated "thoughts" to each other via push notifications.

To test the full experience, two devices can be paired with a code (Settings → account), but core functionality (compass, instruments, send/receive animations) can be exercised on a single device using the built-in flow. Location permission powers the compass direction and stays on-device. Apple Sign In is used for identity and pairing.

50% of Pro purchases are donated to organizations supporting families separated by distance (currently military families).
```
